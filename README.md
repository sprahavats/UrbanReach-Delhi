
# UrbanReach: Urban Accessibility and Road-Network Analysis

## Overview
UrbanReach is a geospatial research project investigating urban accessibility
and road-network connectivity in South Delhi, India.

## Research Question
How accessible are essential services from different neighbourhoods,
and how does accessibility change when the road network is disrupted
or improved?

## Technologies
- Python
- OSMnx
- NetworkX
- GeoPandas
- Shapely
- Pandas
- Folium
- QGIS

## Planned Analysis
- Extract and analyse OpenStreetMap walking networks.
- Calculate network-based distances to essential services.
- Compare accessibility across neighbourhoods.
- Simulate road closures and network improvements.
- Visualise findings through maps and statistical summaries.
